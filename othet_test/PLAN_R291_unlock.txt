============================================================================
NOTES ON NONCE/nc TRACKING:
============================================================================
- Nonce is always "1000"
- nc (nonce count) increments with each request (00000001, 00000002, ...)
- cnonce is chosen by client (any 16 hex chars)
- Both URL Digest params AND Authorization header must use the SAME 
  nonce count (nc) value, but different cnonce values
- Wait 5 seconds between requests (server might be slow)
