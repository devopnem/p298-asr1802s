Brief Manual for Installing the OpenWRT Firmware. (on the example of YOTA C300-1)

Attention! Before the firmware version from Megafon in OpenWrt, you must unlock the LTE module according to a permanent scheme, because the temporary unlock when firmware is lost!

UPD: There was a problem of low outgoing speed on the OpenWrt firmware, most likely this is due to the fact that it does not have the means to switch the LTE antennas. As a temporary solution, you can try to put external antennas "horns"

1. Connect the device to the Internet with a cable through the WAN connector, or through the SIM card. Go to the web interface of the standard firmware. Check the availability of an update if the update is available, then updated. (to have a valid version of the LTE module firmware). After the update, pull out the SIM card.
2. According to the instructions of the C300-1finival.pdf(hereinafter referred to the Instruction) we get access to the factory firmware through the SSH and perform constant unlocking by the method of replacing IMEI. (if you have not already done so before)

3. We keep the Instructions just in case mtd4.bin, which in case of what it would be possible to restore the factory firmware.
4. Next, you need to find out the initialization code of our LTE module, for this we connect via PUTTY and give command:
ubus call version set_atcmd_info '{"atcmd":"at+reset'}'|cat /dev/log_radio|grep "CHECKATVALID"
. The module is reloaded and information is displayed on the screen. Find the code AT +CHECKATVALID=1234567890123456(You will have your own numbers) this code is saved, we still need it.
5. Here we give a team
fw_printen wind bootrgs
and see what the mtddlock parameter is displayed. If mitblock5 is not doing anything else. If mitblock6, then we give the command
fw_setenov bootargs "console=ttyS1,57600n8 root=/dev/dtblock5"

6. Download the link from the poison R281 OpenWRT24.10.2 Openwrt-ramips-mt7621-notion_r281-schashfs-factory.bin, rename it into firmware.bin and stitched by Instructions in mode death (using tftd32/64).
7. The next step through the web interface is the openwrt-ramips-mt7621-notion_r281-ssashsups-sysupgrade.bin file openwrt-ramips-mt761.1.1, root logs, password notion). Wifi SSID is available and password is generated by a script. SSID: Notion-0dra31-5G and Notion-0dra31 (you will have other numbers) Password OP0dra31 (you have other numbers). It is better to change the password for safety.
8. To bind the LTE module, connect via WINSCP login:root, password:noten and edit /etc/gcom/ncm.json file. We find in it through a search by the word "notion", the desired paragraph and add the item :"AT+CHECKATVALID=12344578901346356", (write your number obtained in the previous stage)
It should look like this (the numbers you have yours)
"notion": {    
"Initialize": [        
"AT*APOWERIND=0",        
"AT+CHECKATVALID=1234567890123456",        
"AT+CFUN=1"        
"AT+CMGF=1",        
"AT+CNMI=2,1,0,0,0"

Preserving the changes.
Turn off, insert the SIM card. Turn on. If everything is done correctly, the Internet should appear.

UPD: Never found AT antenna control commands for the PXA1826 module
You can also experiment with AT teams, you can enter SSH via atcmd. Example:
atcmd AT+CLAC
Displays the list of AT teams.

However, for a long time he tested when connecting the Internet through WAN. There are no complaints about stability in this mode.
UPD: The firmware is compiled from the fork from LENAR, but unlike the prototype, I have collected based on the latter files at the moment stable release of OPENWRT 24.10.2. Made with a minimum of packages to ensure maximum performance. Corrected to our hardware .dts file description of the device, because the one that was, was not compatible with the drivers of wi-fi 5Gz (although I asked Lenar and he sent me screenshots - he works with that dts). Refined the vermagic check and inserts. Replaced the package for smsms luci-app-sms-tool with the current luci-app-s-stool-js and added two MTm-json modem extension files to the ncm.json modem file for configure SMS modem (I did not display SMS without these commands). Added to the assembly packages AmneziaWG, it was necessary to put and Wireguard, because without it amnesia was not installed. Added auxiliary kernel packages required for Podkop and SingBox-a.
