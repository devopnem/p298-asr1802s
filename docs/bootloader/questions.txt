Load address needs confirming at runtime. I'll read the actual RAM layout from bdinfo at Phase 1 rather than trusting the DTB, because the memory node (base 0x4000000, size 0x8000000) and U-Boot's own mem=512M@0x%x strings don't agree on the total. 0x8000000 is provisional.
Fastboot boot is the wrong command here. It expects an Android boot image (ANDROID! magic); yours is a raw zImage + appended DTB. Hence staging via download then hand-booting with bootz.
